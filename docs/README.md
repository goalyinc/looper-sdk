# docs/

The SDK's API reference, the reference pages of
<https://looper.goaly.ai/wiki/api-reference.html>. The pages are generated
from `looper_sdk`'s docstrings, so a change belongs in a docstring, never in
a page.

| File | What it holds |
|---|---|
| `api-reference.md` | The clients: `ServiceClient`, `TrainingClient`, `Operation`, `SamplingClient`, `SamplingOperation` and the states they report |
| `api-values.md` | The values a program builds and the results it reads |
| `api-errors.md` | Every exported error, at a glance and with its attributes |
